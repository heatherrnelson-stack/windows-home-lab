# Ubuntu VM Installation

## Objective
Install Ubuntu Linux in VirtualBox to begin learning Linux administration and virtualization.

## Environment
- Host OS: Windows 11
- Virtualization Software: VirtualBox
- Guest OS: Ubuntu Linux

## Installation Steps
1. Download Ubuntu ISO
2. Install VirtualBox
3. Create virtual machine
4. Allocate RAM and storage
5. Mount ISO file
6. Install Ubuntu

## Skills Learned
- Virtual machine provisioning
- Linux installation
- ISO mounting
- VirtualBox configuration
